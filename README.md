# SLAM: Explore the Unknown World

## Class Work 8

## สถานการณ์ปัญหา

นักศึกษาถูกส่งหุ่นยนต์ **RoboMaster** เข้าไปสำรวจพื้นที่ที่ไม่ทราบแผนที่ล่วงหน้า โดยหุ่นยนต์ต้องใช้เซนเซอร์และกระบวนการ **SLAM (Simultaneous Localization and Mapping)** เพื่อสร้างแผนที่และประมาณตำแหน่งของตนเอง

### เงื่อนไขของภารกิจ

- หุ่นยนต์ไม่สามารถมองเห็นแผนที่ก่อนเริ่มภารกิจ
- หุ่นยนต์ต้องสำรวจพื้นที่ด้วยตนเอง
- หุ่นยนต์ต้องสร้างแผนที่จากเซนเซอร์ เช่น
  - TOF Sensor
  - Sharp Sensor
- หุ่นยนต์ต้องสามารถประมาณตำแหน่งของตัวเองได้
- เมื่อจบภารกิจ ต้องรายงานข้อมูลต่อไปนี้:
  - จุดเริ่มต้นของหุ่นยนต์
  - จุดสิ้นสุดของหุ่นยนต์
  - เส้นทางที่หุ่นยนต์เคลื่อนที่

## กำหนดส่งงาน

ส่งงานวันจันทร์ที่ **28 กันยายน 2569** ในคาบเรียน

โดยแต่ละกลุ่มจะต้องทดสอบหุ่นยนต์ตามลำดับที่กำหนด

## สิ่งที่ต้องส่ง

### 1. Map

แผนที่ที่สร้างได้จากการสำรวจของหุ่นยนต์

### 2. Exploration Log

บันทึกข้อมูลระหว่างการสำรวจ เช่น

- ค่าที่อ่านได้จากเซนเซอร์
- ตำแหน่งของหุ่นยนต์
- เวลาในการสำรวจ
- คำสั่งการเคลื่อนที่

### 3. Robot Trajectory

เส้นทางการเคลื่อนที่ของหุ่นยนต์ ตั้งแต่จุดเริ่มต้นจนถึงจุดสิ้นสุด

### 4. การวัดความถูกต้อง

นำแผนที่ที่หุ่นยนต์สร้างได้มาเปรียบเทียบกับ **Ground Truth Map**

#### Map Accuracy

```text
Map Accuracy =
(จำนวน Cell ที่ทายถูก / จำนวน Cell ทั้งหมด) × 100
```

#### Coverage

```text
Coverage =
(จำนวน Cell ที่สำรวจแล้ว / จำนวน Cell ทั้งหมด) × 100
```

### 5. การนำเสนอ

เตรียมนำเสนอหลักการทำงานของระบบ โดยอธิบายหัวข้อต่อไปนี้:

- หลักการสำรวจพื้นที่
- หลักการสร้างแผนที่
- เซนเซอร์ที่ใช้
- วิธีการประมาณตำแหน่งของหุ่นยนต์
- วิธีการวางแผนเส้นทาง
- ผลการทดลอง
- ปัญหาที่พบและแนวทางการแก้ไข
- ค่าความถูกต้องของแผนที่
- ค่า Coverage

## ผลลัพธ์ที่คาดหวัง

เมื่อจบภารกิจ ระบบควรสามารถ:

- สร้างแผนที่ของพื้นที่ได้
- บันทึกข้อมูลการสำรวจได้
- แสดงเส้นทางการเคลื่อนที่ของหุ่นยนต์ได้
- ประมาณตำแหน่งเริ่มต้นและตำแหน่งสุดท้ายได้
- คำนวณค่า Map Accuracy และ Coverage ได้

> เป้าหมายคือให้หุ่นยนต์ “รู้ว่าตัวเองอยู่ที่ไหน” พร้อมกับ “รู้ว่ารอบตัวมีอะไรบ้าง” — นี่แหละหัวใจของ SLAM
