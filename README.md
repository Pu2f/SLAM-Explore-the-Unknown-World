# SLAM-Explore-the-Unknown-World
Class Work 8: SLAM-Explore the Unknown World
สถานการณ์ปัญหา
นักศึกษาถูกส่งหุ่นยนต์ RoboMaster เข้าไปสำรวจพื้นที่ที่ไม่ทราบแผนที่ หุ่นยนต์ได้รับข้อมูลเพียงว่า
    • หุ่นยนต์ไม่สามารถมองเห็นแผนที่ก่อนเริ่มภารกิจ 
    • หุ่นยนต์ต้องสำรวจพื้นที่ด้วยตัวเอง 
    • หุ่นยนต์ต้องสร้างแผนที่จาก Sensor  TOF หรือ sharp sensor 
    • หุ่นยนต์ต้องสามารถประมาณตำแหน่งของตัวเอง 
    • เมื่อจบภารกิจต้องรายงานว่า หุ่นยนต์เริ่มต้นที่ไหน และจบที่ไหน

สิ่งที่จะต้องส่งในวันจันทร์
    1. Map : แผนที่ที่ได้จากการสำรวจของหุ่นยนต์
    2. Log ข้อมูลการสำรวจ
    3. Robot Trajectory แสดงเส้นทางที่ Robot เคลื่อนที่
    4. การวัดความถูกต้อง : นำ Map ที่สร้างได้มาเปรียบเทียบ Ground Truth Map
    • Map Accuracy  =  (จำนวน Cell ที่ทายถูก/ จำนวน Cell ทั้งหมด) x 100
    • Coverage = (จำนวน Cell ที่สำรวจแล้ว/จำนวน Cell ทั้งหมด) x 100
    5. เตรียมนำเสนอ อธิบาย หลักการที่ใช้ในการสำรวจและสร้างแผนที่รายกลุ่ม
